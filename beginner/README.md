# Beginner — Data Structures and Algorithms

This section covers the foundational concepts of Data Structures and Algorithms required to build strong problem-solving skills and confidently solve LeetCode Easy problems.

The focus here is on understanding basic data structures, algorithmic thinking, and common patterns before moving on to more complex topics.

## Topics Covered

### Core Foundations
- Time and space complexity (basic understanding)
- Big-O notation (introductory)
- Basic problem-solving techniques

### Data Structures
- Arrays
- Strings
- Hashing (HashMap, HashSet basics)

### Algorithms and Techniques
- Recursion (basic)
- Searching (linear search, basic binary search)
- Sorting (bubble, selection, insertion)
- Two pointers (basic usage)
- Prefix sum (introductory)

### Problem-Solving Focus
- Pattern recognition
- Translating problems into code
- Writing clean and efficient solutions in Java

## Goal
To build a strong foundation in data structures and algorithms and develop the confidence to solve LeetCode Easy problems independently using Java.
